# Glossário

| Termo | Definição operacional |
|---|---|
| ADR | Registro do contexto, decisão arquitetural e consequências. |
| Alert | Sinal produzido quando uma condição de detecção é atendida. |
| ATT&CK | Base de conhecimento de táticas e técnicas adversárias da MITRE. |
| Baseline | Comportamento de referência usado para identificar desvios. |
| Detection Engineering | Disciplina de projetar, testar, operar e melhorar detecções. |
| DFIR | Digital Forensics and Incident Response. |
| EDR | Detecção e resposta com foco em endpoints. |
| ETW | Infraestrutura de tracing de eventos do Windows. |
| False negative | Atividade relevante que a detecção não sinalizou. |
| False positive | Alerta correto pela lógica, mas sem relevância maliciosa no contexto. |
| Honeypot | Sistema de engano destinado a observar interações não esperadas. |
| IOC | Indicador observável associado a atividade potencialmente maliciosa. |
| IOA | Padrão comportamental que indica ação adversária. |
| LOLBin | Binário legítimo usado de maneira abusiva. |
| MTTD | Tempo médio até a detecção. |
| NTP | Protocolo de sincronização de tempo. |
| NSM | Network Security Monitoring. |
| Playbook | Procedimento repetível para análise ou resposta. |
| Purple Team | Colaboração entre capacidades ofensivas e defensivas. |
| SIEM | Plataforma de centralização, busca e correlação de eventos. |
| Sigma | Formato genérico de regras de detecção baseadas em logs. |
| SOAR | Orquestração e automação de operações de segurança. |
| STIX | Linguagem estruturada para threat intelligence. |
| Sysmon | Serviço do Sysinternals que produz telemetria detalhada do Windows. |
| TAXII | Protocolo para intercâmbio de threat intelligence. |
| Telemetria | Dados observáveis produzidos por sistemas e sensores. |
| Threat hunting | Busca proativa, orientada por hipótese, por atividade adversária. |
| TIP | Plataforma de gestão de inteligência de ameaças. |
| TTP | Tática, técnica ou procedimento usado por um ator. |
| YARA | Linguagem de regras para identificar padrões em artefatos. |
| XDR | Detecção e resposta correlacionando múltiplos domínios. |
