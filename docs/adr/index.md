# Architecture Decision Records

ADRs preservam decisões que influenciam várias partes do projeto. Estados possíveis: **Proposto**, **Aceito**, **Substituído** e **Rejeitado**.

| ADR | Decisão | Estado |
|---|---|---|
| [0001](0001-wazuh-primary-platform.md) | Wazuh como plataforma principal | Aceito |
| [0002](0002-sysmon-windows-telemetry.md) | Sysmon para telemetria Windows | Aceito |
| [0003](0003-mkdocs-documentation.md) | MkDocs Material para documentação | Aceito |
| [0004](0004-wazuh-deployment-strategy.md) | VM Linux all-in-one no VirtualBox | Aceito e implementado |

Crie novos registros a partir de `templates/adr-template.md`. Não altere silenciosamente uma decisão aceita; crie um novo ADR que a substitua.
