# Ferramentas

Os capítulos serão desenvolvidos conforme cada componente for implantado e observado no laboratório.

| Ferramenta | Foco do capítulo | Release prevista |
|---|---|---|
| Wazuh | Arquitetura, implantação, regras e operação | 0.2.0 |
| Sysmon | Eventos, configuração, volume e integração | 0.3.0 |
| auditd | Auditoria Linux e casos de uso | 0.4.0 |
| Zeek | Metadados e protocolos | 0.5.0 |
| Suricata | Assinaturas, tuning e integração | 0.5.0 |
| MISP | Modelagem e enriquecimento | 0.7.0 |
| Velociraptor | Coleta e DFIR | 0.8.0 |

Um capítulo só deve afirmar comportamento verificado ou sustentado por referência primária.
