# Contribuindo

## Fluxo

1. Abra uma issue descrevendo problema, hipótese ou melhoria.
2. Crie uma branch curta e focada.
3. Faça mudanças pequenas, com justificativa e evidências.
4. Execute `mkdocs build --strict`.
5. Abra um pull request usando o template.

## Padrões

- Escreva em português claro e preserve nomes técnicos consagrados.
- Use UTF-8, finais de linha consistentes e links relativos.
- Não inclua segredos, dados pessoais, malware funcional ou evidências não sanitizadas.
- Detecções devem indicar fonte, ATT&CK, falsos positivos, teste e limitações.
- Decisões duradouras devem criar ou atualizar um ADR.

Contribuições devem respeitar o [Código de Conduta](CODE_OF_CONDUCT.md).
